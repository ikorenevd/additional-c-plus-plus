Тесты запускаются командой `make test` из каталога `task_1`.
Для отдельной проверки сборки используйте `make`.

Обычная сборка компилируется и линкуется с `-nostdlib`, без библиотеки
времени выполнения C++. Исключения и RTTI отключены; операции `new[]`
и `delete[]`, необходимые классу `block`, реализованы в `test_runtime.cpp`
через `malloc` и `free`. При нехватке памяти группа тестов завершается
с ошибкой. Заголовочные средства C++ (`array`, алгоритмы, `numeric_limits`)
не требуют подключения библиотеки C++.

Это не сборка без всех системных библиотек: классы и тесты используют
C/POSIX для вывода, памяти, математических функций и дочерних процессов.
Makefile рассчитан на Linux с GCC и явно подключает `libc`, `libm`,
`libgcc` и стартовые объектные файлы GCC. Исходные файлы и зависимости
от заголовков перечислены явно. Доступные цели: `all`, `test`, `clean`.

Каждая группа выполняется в отдельном процессе: авария одной группы не
останавливает остальные. Ненулевой код возврата означает провал проверки
или аварийное завершение группы. Проверки ожидаемого `assert` пропускаются
при сборке с `NDEBUG`.
